تاوني Games - طريقة التشغيل على GitHub
========================================

الأوفلاين (بدون روم): ارفع كل الملفات على GitHub Pages وخلاص. اللعبة بتشتغل وبتتثبّت على التليفون وبتشتغل من غير نت.

الأونلاين (رومز مع صحابك) محتاج Firebase مجاني. مرة واحدة بس:

1) روح console.firebase.google.com واعمل Project جديد (ممكن تقفل Google Analytics).
2) جوه الـ Project: اضغط علامة الويب </> لإضافة Web app. اكتب أي اسم وانسخ القيم (apiKey و authDomain و projectId و appId).
3) افتح ملف firebase-config.js والصق القيم مكان "ضع-...-هنا".
4) من القايمة: Build > Firestore Database > Create database. اختار أقرب منطقة، واختار Production mode.
5) افتح تبويب Rules في Firestore، امسح اللي موجود والصق محتوى ملف firestore.rules، واضغط Publish.
   (ملحوظة: ماتستخدمش Test mode. بيقفل لوحده بعد 30 يوم وساعتها الأونلاين هيبوظ.)
6) على GitHub: Settings > Pages > اختار الفرع main والفولدر root. استنى دقيقة وافتح اللينك.
7) على تليفونك: افتح اللينك > "Add to Home Screen". صاحبك يفتح نفس اللينك. واحد يعمل روم والتاني يكتب الكود.

لو الأونلاين مش شغال:
- شوف إن ملف firebase-config.js فيه القيم الصح من غير علامات ناقصة.
- شوف إنك نشرت الـ Rules (خطوة 5).
- لو ظهر شريط أحمر "الاتصال ضعيف" يبقى النت عندك أو عند صاحبك ضعيف، اللعبة بتحاول تاني لوحدها.
- بعد أي تحديث للملفات على GitHub، افتح اللعبة مرتين عشان النسخة الجديدة تتحمّل.

المجاني في Firebase كفاية جداً للعب مع الأصحاب (50 ألف قراءة و20 ألف كتابة يومياً، والنبضة اللي بتثبّت الأونلاين بتاخد جزء بسيط منها).
لو صاحب الروم قفل اللعبة في نص الماتش، واحد من الباقيين بيبقى هو المضيف تلقائياً بعد حوالي دقيقة.
